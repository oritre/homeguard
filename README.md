# 🛡️ HomeGuard – בקרת הורים למחשבי הבית

כל ילד מקבל שם משתמש וסיסמה משלו. אחרי שנכנסים ל-Windows מופיע מסך נעילה שמכסה את כל המסכים.
הילד מקליד שם משתמש וסיסמה, ואתם (אבא ואמא) מקבלים בטלגרם הודעה עם כפתורים: סוג גישה ומשך זמן בלחיצה אחת.
מי שעונה ראשון קובע, וההודעה מתעדכנת אצל שניכם.

## איך זה עובד

```
 ┌────────── מחשב של הילדים (כל אחד) ──────────┐          ┌──── מחשב שתמיד דלוק ────┐
 │                                             │          │  (ההורים / Raspberry Pi) │
 │  מסך נעילה (lockscreen.pyw)                 │          │                         │
 │   רץ אצל המשתמש המחובר ─┐                   │   LAN    │  homeguard_server.py    │
 │                         ▼ 127.0.0.1:8765    │ ───────► │   • API לסוכנים :8800   │
 │  סוכן (homeguard_agent.py) רץ כ-SYSTEM      │          │   • בוט טלגרם           │──► 📱 טלגרם
 │   • חומת אש: אינטרנט פתוח/סגור              │          │   • SQLite: ילדים,       │    שלך ושל אשתך
 │   • DNS מקומי: סינון אתרים                  │          │     זמנים, אתרים         │
 │   • מנתק משתמש אם מסך הנעילה נסגר            │          └─────────────────────────┘
 └─────────────────────────────────────────────┘
```

**שלושה סוגי גישה** (כפתורים בטלגרם, כל אחד ל-30 דק' / שעה / שעתיים):

| | מצב | מה קורה |
|---|---|---|
| 🌐 | אינטרנט מלא | הכל פתוח חוץ מהאתרים ברשימה החסומה, דרך DNS משפחתי (Cloudflare 1.1.1.3) שחוסם תוכן למבוגרים ונוזקות |
| ✅ | רק אתרים מאושרים | רק האתרים שברשימה המאושרת (`/allow`). יוטיוב, גוגל, ויקיפדיה ועוד מקבלים אוטומטית את שרתי התמונות והווידאו שהם צריכים |
| 🚫 | בלי אינטרנט | המחשב עובד, אבל אין יציאה לאינטרנט (הרשת הביתית נשארת פתוחה) |

**זמן:** טיימר קטן בפינת המסך עם "עוד זמן" (שולח לכם בקשה עם +15/+30/+60) ו"סיימתי". חמש דקות לפני הסוף הטיימר נהיה כתום, דקה לפני אדום, ובסוף המסך ננעל שוב ואתם מקבלים הודעה.

**פקודות בבוט:** `/status` (מי מחובר + כפתור נעילה), `/lock`, `/extend סלון 30`, `/allow`, `/block`, `/unallow`, `/unblock`, `/sites`, `/kids`.

**החשבונות שלכם פטורים:** כשאתם מחוברים ל-Windows במחשב (המשתמשים ב-`ExemptUsers`) אין מסך נעילה ואין סינון.

## מה מתקינים

**פעם אחת, על מחשב שתמיד דלוק (השרת):**
1. בטלגרם, פתחו את `@BotFather`, שלחו `/newbot` וקבלו token.
2. `install\install-server.ps1 -TelegramToken <token>` (PowerShell כמנהל). הסקריפט מתקין Python אם צריך, מגדיר משימה שעולה עם המחשב, ומדפיס את כתובת השרת ואת ה-Agent token.
3. כל אחד מכם שולח לבוט `/start` ומקבל מזהה צ'אט. מריצים שוב: `install-server.ps1 -TelegramToken <token> -ParentChatIds 111,222`.
4. מוסיפים ילדים: `python homeguard_server.py kid add noam 1234 נועם --config C:\ProgramData\HomeGuardServer\config.json`
5. מומלץ: כתובת IP קבועה לשרת בראוטר.

(על Raspberry Pi / לינוקס: `install/homeguard-server.service`.)

**על כל מחשב של הילדים (כמנהל):**
```powershell
powershell -ExecutionPolicy Bypass -File install\install-agent.ps1 `
    -ServerUrl http://192.168.1.10:8800 -AgentToken <token> -PcName "סלון" -ExemptUsers "ori","wife"
```
הסקריפט מתקין Python 3.12 לכל המשתמשים (winget), מעתיק ל-`C:\Program Files\HomeGuard`, שומר הגדרות שרק מנהל יכול לקרוא,
מכבה DNS-over-HTTPS בכרום/אדג'/פיירפוקס/בריב, ורושם שתי משימות: הסוכן (SYSTEM, עם עליית המחשב) ומסך הנעילה (בכל כניסה, ונפתח מחדש כל דקה אם נסגר).

**חובה:** חשבון ה-Windows של הילדים הוא **Standard user** (לא Administrator). אפשר חשבון אחד משותף לכל הילדים, כי הזיהוי נעשה במסך הנעילה.

הסרה: `install\uninstall-agent.ps1` מחזיר את חומת האש וה-DNS לברירת המחדל.

## הגנות מעקיפה

- המחשב נעול כברירת מחדל: בלי אישור, חומת האש חוסמת יציאה לאינטרנט. אם השרת לא זמין, הזמן שכבר אושר ממשיך לרדת ואז ננעל.
- אם מסך הנעילה נסגר/נהרג ולא חוזר תוך 45 שניות, הסוכן מנתק את המשתמש מ-Windows.
- לחשבון הילד נחסמים מנהל המשימות וקיצורי מקש Windows (Win+Tab וכו'), בתוקף מהכניסה השנייה.
- 5 סיסמאות שגויות ב-10 דקות: חסימה זמנית והתראה אליכם.
- מצב "אתרים מאושרים" חוסם לפי שם אתר (DNS). גישה ישירה לכתובת IP, VPN או דפדפן נייד עם DNS משלו עלולים לעקוף. זה מספיק לרוב הילדים, ושלב הבא יכול להוסיף חסימה גם לפי חומת אש.

## מבנה

```
server/homeguard_server.py   שרת + בוט טלגרם (Python, בלי ספריות חיצוניות)
agent/homeguard_agent.py     סוכן SYSTEM: חומת אש, DNS, API מקומי, שומר
agent/dnsfilter.py           שרת DNS מסנן (UDP+TCP)
agent/winctl.py              קריאות Windows (WTS, netsh, PowerShell, רישום)
agent/lockscreen.pyw         מסך הנעילה והטיימר (tkinter)
install/                     סקריפטי התקנה והסרה
tests/                       בדיקות: python -m unittest discover -s tests
```
