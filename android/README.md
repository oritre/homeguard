# 🛡️ HomeGuard לאנדרואיד

אותו שרת, אותו בוט ואותם חשבונות כמו במחשבים. הילד מתחבר עם שם המשתמש והסיסמה שלו, ואתם מאשרים בטלגרם.

## מה האפליקציה עושה

- **מסך נעילה** מעל כל האפליקציות עד שאבא/אמא מאשרים. יש בו גם "שינוי סיסמה", בחירת סיסמה אישית בכניסה הראשונה, וכפתור "שיחת חירום".
- **טיימר בהתראה** עם הכפתורים "עוד זמן", "בקשת אתר" (מקלידים כתובת ישר בהתראה) ו"סיימתי". חמש דקות ודקה לפני הסוף מגיעה התראה.
- **סינון אינטרנט** דרך VPN מקומי בטלפון (שום דבר לא יוצא החוצה): 🌐 מלא חוץ מאתרים חסומים, ✅ רק אתרים מאושרים, 🚫 בלי אינטרנט. עובד גם בחבילת גלישה.
- **בבית ומחוץ לבית:** האפליקציה מנסה קודם את כתובת השרת בבית, ואם היא לא זמינה, את הכתובת החיצונית (Tailscale Funnel). אם אין חיבור בכלל, הזמן שאושר ממשיך לרדת ואז המכשיר ננעל.

## התקנה עם הגנה מלאה (אחרי איפוס)

כשהאפליקציה מוגדרת כ"מנהלת המכשיר" (Device Owner), הילד לא יכול למחוק אותה, לכבות את ה-VPN, להפעיל מצב בטוח או לשנות DNS פרטי.

1. **איפוס להגדרות יצרן.** באשף ההתחלה מתחברים ל-Wi-Fi, אבל **לא מוסיפים חשבון גוגל ולא חשבון סמסונג** (מדלגים). חשוב: אם יש חשבון במכשיר, שלב 5 ייכשל.
2. **הפעלת מצב מפתחים:** הגדרות ← אודות הטלפון ← מידע על תוכנה ← 7 לחיצות על "מספר גרסת Build". אחר כך: הגדרות ← אפשרויות מפתחים ← **ניפוי באגים ב-USB**.
3. **במחשב:** מתקינים כלי adb (`winget install Google.PlatformTools`), מחברים כבל ומאשרים בטלפון "לאפשר ניפוי באגים".
4. מתקינים את האפליקציה (את הקובץ `homeguard.apk` מורידים מ-Releases בריפו):
   ```
   adb install homeguard.apk
   ```
5. קובעים אותה כמנהלת המכשיר:
   ```
   adb shell dpm set-device-owner com.oritre.homeguard/.AdminReceiver
   ```
   התשובה צריכה להיות `Success: Device owner set to package ...`
6. **בטלפון** פותחים את HomeGuard וממלאים: כתובת השרת בבית, כתובת חיצונית, Agent token, שם למכשיר וקוד הורים. מאשרים את כל ההרשאות לפי הסדר (הצגה מעל אפליקציות, VPN, סוללה, התראות) ולוחצים "שמירה והפעלה".
7. עכשיו אפשר להוסיף את חשבון הגוגל של הילד ולכבות את ניפוי הבאגים ב-USB.

**בסמסונג** כדאי גם: הגדרות ← סוללה ← הגבלות שימוש ברקע ← להוסיף את HomeGuard ל"אפליקציות שלעולם לא יושבתו".

**עדכון גרסה:** `adb install -r homeguard.apk` (כל הגרסאות חתומות באותו מפתח, אז ההגדרות נשמרות).

**הסרה:** במסך ההגדרות (עם קוד ההורים) לוחצים "הסרת ההגנה מהמכשיר", ואז אפשר למחוק את האפליקציה כרגיל.

## התקנה בלי איפוס (הגנה בסיסית)

מדלגים על שלבים 1, 2, 3 ו-5 ומתקינים את ה-APK ישירות בטלפון. הכל עובד, אבל ילד שמבין יכול להסיר את האפליקציה או לכבות את ה-VPN. במקרה כזה המכשיר ננעל, ואם הוא נמחק, תראו ב-`/status` שהמכשיר לא מחובר.

## כתובת חיצונית (Tailscale Funnel)

על המכונה שמריצה את השרת (היום ה-Pi של Home Assistant, דרך תוסף Tailscale), או על מחשב עם Tailscale:
```
tailscale funnel --bg 8800
```
בפעם הראשונה Tailscale ייתן קישור לאישור Funnel בחשבון. אחרי זה `tailscale funnel status` יציג כתובת בסגנון `https://desktop-2tqgn0a.tailXXXX.ts.net`, ואותה מכניסים בשדה "כתובת השרת מחוץ לבית".

## מגבלות ידועות

- הסינון הוא לפי שם אתר (DNS). VPN אחר לא יכול לפעול במקביל, ובמצב מנהל המכשיר הילד גם לא יכול להתקין אחד.
- מסך הנעילה לא מופיע מעל מסך הנעילה של אנדרואיד עצמו, אלא מיד אחרי שפותחים את המכשיר.
